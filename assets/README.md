# Web Assets

Deze folder bevat assets voor de web versie van de app. Expo zal automatisch de benodigde assets genereren tijdens de build.

Voor een volledig functionerende deployment heb je de volgende assets nodig:
- icon.png (1024x1024)
- splash.png (1284x2778 voor moderne devices)
- favicon.png (48x48 of 32x32)
- adaptive-icon.png (1024x1024, Android)
